# تولیدی کیف سینا — SinaBag

سایت رسمی تولیدی کیف سینا (طرح ۸ «دسته‌بندی بزرگ») — کاملاً استاتیک، تک‌فایله و بدون وابستگی خارجی.

## ساختار
- `index.html` — صفحهٔ اصلی (RTL، فارسی؛ CSS و JS داخلی)
- `fonts/` — فونت وزیرمتن (woff2، self-host)
- `img/` — تصاویر محصولات و favicon

## استقرار روی Vercel
1. در vercel.com → **Add New → Project**
2. مخزن `euphemiaa/SinaBag` را Import کنید
3. Framework Preset را روی **Other** بگذارید (Build لازم ندارد)
4. **Deploy** بزنید — تمام.
